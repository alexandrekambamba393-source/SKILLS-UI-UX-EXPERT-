# Minimalism: Design Instructions

## Core principle
Every element must earn its place. Remove any element whose absence does not reduce the user's ability to complete the task. Minimalism is not emptiness; it is clarity of hierarchy.

## Process
1. Define the single primary task of the screen in one sentence.
2. Inventory every element and classify it as essential, supporting or decorative. Delete decorative elements first.
3. Allow exactly one primary action per view. Secondary actions use a ghost or text style.
4. Use an 8px spacing scale: 8, 16, 24, 32, 48, 64, 96. Never use arbitrary values.
5. Palette: one background, one text color, one accent, plus up to four neutral tones for borders and muted text.
6. Typography: one font family, at most four sizes, two weights (regular and semibold).
7. Group with proximity and whitespace before reaching for borders, boxes or dividers.
8. Motion is brief (150 to 200 ms, ease-out) and only signals a state change.

## Quality checklist
- Body text contrast is at least 4.5:1 (WCAG 2.2 AA).
- Each screen has one dominant focal point.
- Icons are paired with a text label unless their meaning is universal.
- Line length stays between 45 and 75 characters.
- Empty space is intentional: remove a component before shrinking whitespace.

## Anti-patterns
Decorative gradients, drop shadows on every card, more than one accent color, body text under 14px on desktop, icons without labels for critical actions, and hairline dividers used in place of spacing.
